# v0.3-bata Windowsビルド ExecPlan

## Purpose and acceptance

直前のフルデバッグを通過した現在の未コミット作業ツリーから、ユーザー指定ラベル`v0.3-bata`のWindows one-dir配布物を生成する。正式scriptの`-SystemVcRuntime`を使い、標準Microsoft VC++ runtime DLLを同梱せず、公式Redistributable installer導線、Qt/CPythonを含むライセンス素材、Factory data filesを含める。最終成果物は`dist/LoRA Factory_v0.3-bata-windows-x64.zip`と同名`.sha256`で、hash照合、内容監査、ローカル起動smokeを通す。

既存source差分を保持し、commit、push、tag、GitHub releaseは行わない。raw画像、managed runtime、vendor、ユーザープロジェクトを変更しない。同名成果物が存在する場合は上書きせず停止する。

## Architecture and milestones

1. Input gate: Git差分、lock、target不存在、label安全性を確認する。
2. Build: frozen build extraとpinned PyInstallerでone-dirを生成し、license exporterを実行する。
3. Audit: required data/license/install files、VC runtime不在、不要Qt/CUDA/model weight不在を検査する。
4. Package: workflowと同じ命名でZIPを作成し、SHA-256 sidecarを書き、ZIP hashと内容を再照合する。
5. Smoke: packaged GUIをoffscreen起動し、task processだけを停止する。
6. Cleanup: PyInstaller workを削除し、`.venv`を通常frozen環境へ戻し、成果物とログだけを残す。

## 2026-08-26 QtWidgets DLLロード障害の修正と指定ZIP上書き

### 再現と原因

- 外部OBS QtをPATH先頭に置いた配布EXEで、QtWidgets import時にWinError 127（指定されたプロシージャが見つかりません）を再現した。
- PyInstallerがビルドホストのPoppler由来icuuc.dllとicudt78.dllを配布物へ収集していた。Qt6Coreが要求する未修飾ICUシンボルとPoppler ICUのicu_78修飾シンボルが不一致となるため、PATHを固定しても依存DLLで衝突した。

### 修正

- src/lora_factory/qt_runtime.pyを追加し、PySide6/shiboken6のDLLディレクトリを起動前にos.add_dll_directoryとPATHへ登録する。
- 同モジュールでQt6Core、Qt6Gui、Qt6Widgetsを同梱ディレクトリから絶対ロードし、ハンドルをプロセス終了まで保持する。Windows System32を外部PATHより優先し、QT_PLUGIN_PATHとQML2_IMPORT_PATHも同梱先へ固定する。
- packaging/qt_runtime_hook.pyを追加し、PyInstaller runtime hookとしても同じ初期化を実行する。app.pyはGUI/Qt importをこの初期化後へ遅延した。
- packaging/lora_factory.specでビルドホスト由来のicu*.dllを除外し、QtのWindows標準ICU解決を維持する。tests/unit/test_qt_runtime.pyとspec静的検査へ回帰ケースを追加した。

### 最終成果物と検証

- scripts/build_windows.ps1 -BuildLabel v0.3-bata -SystemVcRuntimeを再実行し、LoRA Factory_v0.3-bata.zipとSHA-256 sidecarを上書き生成した。
- ZIPは599 entries / 513 files。重複、不正パス、必須欠落、標準VCランタイム、ICU、不要Qt、モデル重み、CUDA runtimeは各0件。README反映後のSHA-256はb8a8befeef4c6473d591c8080f3df41fa0fd0a5f7952861c2a993652f45f652b。
- ZIP展開後のEXEをclean PATHと外部OBS Qt PATH＋外部plugin pathで各12秒起動し、QtWidgetsエラー・stderr・残留プロセスは0件だった。
- 最終preflightは720 passed, 6 skipped、coverage 82.98%。Ruff format/check、mypy、uv lock --check、Fake E2Eを含めて成功した。

### 残課題

- SystemVcRuntimeのため、利用者環境に公式x64 VC++ Redistributableが必要であり、install_vcredist.cmdをZIPへ同梱している。clean Windows accountでの導入・Setup・Fake Backend projectは別release gateである。
