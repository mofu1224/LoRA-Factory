# Support

Use GitHub Issues for reproducible defects and feature requests. Check the [Japanese user guide](docs/user-guide-ja.md) and run the Setup checks before reporting a runtime problem.

This is a community project without guaranteed response times. Do not upload private datasets, source images, model weights, tokens, full environment files, or logs containing personal paths. Security vulnerabilities must be reported privately as described in [SECURITY.md](SECURITY.md).
